## Live products

- **[Say/Mean](https://saymean.pfhub.app)**: a daily vocabulary log for saying what you mean. Five words a day, the word each is confused with, and an out-loud articulation drill. Static, dependency-free build with full-history search, per-word pages, RSS, and a strict Content-Security-Policy.
- **[Learn](https://learn.pfhub.app)**: an interactive learning site.
- **[Transiarize](https://transiarize.com)**: a privacy-first, self-hosted AI meeting-intelligence platform. Speech-to-text and speaker diarization run on local models, built for multilingual and code-switched speech.
